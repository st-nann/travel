# Skill: plan.md — Google Sheet trip plan → mobile web page (index.html) → GitHub Pages

ตำแหน่งไฟล์นี้ใน repo: `.claude/skill/plan.md`

ใช้เมื่อผู้ใช้ส่งชีตแผนทริป (แท็บ Plan / Cost / Contact & Location) แล้วบอกว่า "มี update" และต้องการสร้าง/อัปเดต `index.html` พร้อม push ขึ้น GitHub

## Inputs
- ไฟล์ชีตที่ส่งออกมาเป็น CSV/ข้อความ (แท็บ Plan, Cost, Contact & Location) วางไว้ในโฟลเดอร์ทำงาน หรือแนบในแชท (claude.ai อ่านจาก `/mnt/user-data/uploads/`) ห้ามเดาข้อมูลจากลิงก์ Google Sheets ถ้าอ่านไม่ได้ให้ขอไฟล์
- Repo: `git@github.com:st-nann/travel.git` (branch `main`)
- ตำแหน่งไฟล์ใน repo: `<ปี>/<ชื่อทริป>/index.html` เช่น `2026/Rayong/index.html`
- URL หลัง deploy: `https://st-nann.github.io/travel/<ปี>/<ชื่อทริป>/` (ตัวพิมพ์เล็กใหญ่ต้องตรง)

## ขั้นตอนทุกครั้ง
1. อ่านแท็บ **Plan** ใหม่ทั้งหมด อย่าใช้ข้อมูลจากรอบก่อน (ชีตเปลี่ยนบ่อย: เบอร์โทร เวลา ร้าน ลำดับ)
2. สร้าง `index.html` ไฟล์เดียว (HTML+CSS inline) ตามสเปกด้านล่าง
3. ตรวจ: ไม่มีรายการที่ผู้ใช้สั่งเอาออก, เบอร์โทรและลิงก์ตรงกับชีต, ปุ่ม Day 1/2/3 ขนาดเท่ากัน
4. ส่งไฟล์ให้ผู้ใช้ (`present_files`) พร้อมสรุปสั้นๆ ว่าอะไรเปลี่ยนจากรอบก่อน
5. Push ขึ้น GitHub (ดูหัวข้อ Git)

## กติกาการแปลงข้อมูลจากชีต
- แต่ละแถวใน Plan = 1 รายการ: คอลัมน์ A = เวลา, B = ชื่อ, C = รายละเอียด
- ทุกบรรทัดที่เป็น URL ใน C (ใต้คำว่า `Reference`) → ปุ่มลิงก์ใต้หัวข้อ **Reference / Review** ใช้ URL เต็มตามต้นฉบับ (รวม query string) ตั้งชื่อปุ่มตามแพลตฟอร์ม: TikTok / Instagram / Facebook / Lemon8 ถ้ามีแพลตฟอร์มซ้ำให้ใส่เลขต่อท้าย (TikTok 1, TikTok 2) เปิดแท็บใหม่ `target="_blank" rel="noopener"`
- บรรทัด `⏰ เปิด-ปิด: ...` / `• เมนูแนะนำ` ใส่ตามต้นฉบับ (ตัด emoji ⏰ ออกได้)
- เบอร์โทร `โทร: ...` → ลิงก์ `tel:` (ตัดช่องว่าง/ขีด) ถ้ามีหลายเบอร์ทำลิงก์ทุกเบอร์ และคงหมายเหตุในวงเล็บไว้
- ถนนยมจินดา (แถว 13:00 Day 1): แต่ละรายการ `NN ชื่อ — คำอธิบาย` = 1 การ์ด ใน grid 2 คอลัมน์ รายการที่ไม่มีรายละเอียด (เช่น 01, 02) แสดงเฉพาะชื่อ เก็บเลขลำดับตามชีต
- ข้อความในคอลัมน์ข้างๆ ที่ไม่ใช่ C (เช่น เตี๋ยวตั้งโต๊ะ) ถือเป็นโน้ตของแถวนั้น → ทำเป็นการ์ดเพิ่มท้าย grid
- แถวที่ไม่มีวันกำกับ/ลอยท้าย Day 3 (เช่น เคี้ยงติ่มซำ) **ไม่ใส่** ถ้าผู้ใช้เคยสั่งเอาออก
- ไม่ใส่ข้อมูลจากแท็บ Cost (ราคา, ค่าเข้า) ใน index.html นอกจากผู้ใช้ขอ
- ไม่ใส่รูปภาพ: หน้าที่ deploy บน GitHub Pages ไม่ควรพึ่งรูปจากเว็บอื่น และ Claude ดาวน์โหลดรูปจากเว็บ/คลิปไม่ได้ ถ้าผู้ใช้ส่งรูปมาเอง ค่อยฝังเป็นไฟล์แยกในโฟลเดอร์เดียวกัน

## สเปกหน้าตา
- ภาษา `lang="th"`, `viewport-fit=cover`, รองรับมือถือก่อน (max-width ~820px)
- ฟอนต์: **Prompt** จาก Google Fonts (ไทยแบบไม่มีหัว) weight 400/500/700 สำรอง `Noto Sans Thai, system-ui, sans-serif`
- สีประจำวัน: Day 1 `#e86a3c`, Day 2 `#26849f`, Day 3 `#6b8f3a` (เวอร์ชันมืด: `#f08a60`, `#4db3d0`, `#9fc468`)
- พื้นหลัง `#faf6f0` ธีมมืดผ่าน `prefers-color-scheme: dark` กำหนดสีเป็น CSS variables
- แถบ nav ด้านบนแบบ sticky: ปุ่ม Day 1 / Day 2 / Day 3 ขนาดเท่ากัน ลิงก์ไป `#d1 #d2 #d3`
  - **ระวัง:** ห้ามตั้งชื่อคลาสปุ่ม nav ซ้ำกับคลาสเนื้อหา (เคยใช้ `.c` ชนกับกล่องเนื้อหา ทำให้ปุ่ม Day 3 ผิดขนาด) ใช้ `n1 n2 n3`
- แต่ละวัน = หัวข้อสีเต็มกว้าง (ชื่อวัน + วันที่) ตามด้วยไทม์ไลน์: คอลัมน์เวลา (ตัวหนา สีประจำวัน) + เส้นแนวตั้ง + หัวข้อ + รายละเอียด + Reference / Review
- วันที่: Day 1 = พุธ 30 ธ.ค. 2026, Day 2 = พฤหัส 31 ธ.ค. 2026, Day 3 = ศุกร์ 1 ม.ค. 2027 (เปลี่ยนตามทริปใหม่)

## Git / Deploy
Repo: `git@github.com:st-nann/travel.git` (branch `main`)

### เปิด GitHub Pages (ทำครั้งเดียว ผ่านเว็บ GitHub ไม่ต้องใช้คำสั่ง)
1. เปิด https://github.com/st-nann/travel แล้วเช็กว่าตั้งเป็น **Public** (บัญชีฟรีต้องเป็น Public ถึงเปิดเว็บได้)
2. แท็บ **Settings** → เมนู **Pages**
3. **Source**: Deploy from a branch
4. **Branch**: `main` โฟลเดอร์ `/ (root)` → **Save**
5. รอ 1-2 นาที แล้วรีเฟรช จะได้ลิงก์ `https://st-nann.github.io/travel/` ของแต่ละทริปคือ `https://st-nann.github.io/travel/<ปี>/<ชื่อโฟลเดอร์>/`

ข้อควรรู้: ชื่อโฟลเดอร์ในลิงก์ต้องตรงตัวพิมพ์เล็กใหญ่ (`Rayong`) / ถ้า 404 ให้รอแล้วรีเฟรช และดูแท็บ **Actions** ว่า "pages build and deployment" ขึ้นเครื่องหมายถูกสีเขียว / ชื่อบัญชี GitHub จะอยู่ในลิงก์ / แก้แผนทีหลังแค่ push `index.html` ใหม่ทับ

### ถ้าทำงานด้วย Claude Code บนเครื่องผู้ใช้ (แนะนำ)
1. อยู่ในโฟลเดอร์ที่ clone `travel` แล้ว (`git clone git@github.com:st-nann/travel.git`) ผู้ใช้เปิด `claude`
2. สร้างหรืออัปเดต `2026/<ชื่อทริป>/index.html` ตามสเปก
3. แสดง `git status` / `git diff --stat` ให้ผู้ใช้ดู แล้วขอยืนยันก่อน push
4. รัน:
```bash
git add 2026/<ชื่อทริป>/index.html
git commit -m "update <ชื่อทริป> plan"
git push origin main
```
5. แจ้ง URL: `https://st-nann.github.io/travel/2026/<ชื่อทริป>/` รอ 1-2 นาที แล้วรีเฟรชแรงๆ
- ห้ามขอ/รับรหัสผ่าน หรือ token จากผู้ใช้ ใช้ SSH key หรือ credential ที่ตั้งไว้ในเครื่องเท่านั้น
- ห้าม `git push --force` และอย่าแก้ไฟล์อื่นใน repo (เช่น ทริปอื่น) นอกจากผู้ใช้สั่ง

### ถ้าทำงานใน claude.ai (ไม่มี SSH key / push ไม่ได้)
สร้างไฟล์ `index.html` แล้วแนบให้ผู้ใช้ ผู้ใช้อัปโหลดเองผ่านเว็บ GitHub (Add file → Upload files → Commit changes) หรือรันคำสั่ง git ข้างบนเอง
