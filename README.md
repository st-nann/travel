กติกาการอัปเดต:

1. ถ้ามีแท็บชื่อ `Plan (new) - dd.mm.yyyy` ให้อ่านจากแท็บนั้น (ถ้ามีหลายแท็บ ใช้วันที่ล่าสุด)
2. ถ้าไม่มี ให้ใช้แท็บ `Plan (ใหม่)` ในปัจจุบัน

4. อัปเดต `plan.md` และ `index.html` ให้ตรงกันทุกครั้ง
